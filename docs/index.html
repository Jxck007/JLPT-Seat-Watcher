Common questions

What this dashboard knows, and what deliberately stays private.

Is this page the monitor itself?+

No. GitHub Pages is a static presentation layer. The Python monitor runs separately through GitHub Actions or your chosen runtime.

Does the dashboard expose notification secrets?+

No. It reads four sanitized JSON files from GitHub Pages. Provider credentials never reach the browser.

Why can seat data show as pending?+

The dashboard starts with a safe empty snapshot. Seat totals appear after a successful monitor run publishes public state.

Can Watchtower monitor another website?+

Yes. Add an adapter that implements fetch, parse, validate, and notify. The core monitoring engine remains unchanged.
